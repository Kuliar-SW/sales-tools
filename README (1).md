# 제품별 판매량·재고 관리 & 수입 영업이익 계산 도구

사내 판매/재고/영업이익 관리를 엑셀 대신 화면에서 입력·확인할 수 있도록 만든 로컬 프로토타입입니다. 서버·데이터베이스·로그인 없이, 파일 하나(HTML)를 열면 바로 작동합니다.

- `product-sales-tracker.html` — 제품별 고객 판매량 관리 (매출 자동계산, 수입 제품 재고 추적)
- `import-profit-calculator.html` — 수입 제품 영업이익 계산 (수입원가·보관비·운송비 반영)

두 화면은 아직 자동으로 연동되어 있지 않습니다. (향후 데이터베이스 연동 시 통합 예정)

## 대상 사용자

현재는 담당자 1인 사용을 기준으로 만들었습니다. 이후 영업/구매 담당자가 함께 사용할 수도 있습니다.

## 사용 방법

### 1) 제품별 판매량 관리 (`product-sales-tracker.html`)

1. 파일을 더블클릭하거나 브라우저(Chrome, Safari 등)로 열어주세요.
2. 상단 "조회 년월"에서 확인하려는 연도·월을 선택합니다.
3. 제품 카드에서 제품명을 입력하고, 국내/수입 여부를 선택합니다.
   - 국내 제품: 별도 재고 관리 없이 판매량만 입력합니다.
   - 수입 제품: "입고 기록" 표에 수입일자·수입물량을 추가하면 재고가 자동으로 계산됩니다.
4. 고객 표에서 고객명·주문일자·공급일자·공급단가·판매량을 입력하면 매출금액이 자동 계산됩니다. 한 번 입력한 고객명은 이후 자동완성으로 제안됩니다.
5. 여러 고객을 한 번에 등록하려면, 제품 카드 아래 "엑셀에서 붙여넣어 한 번에 채우기" 칸에 엑셀 표(고객명·주문일자·공급일자·공급단가·판매량 순서)를 복사해서 붙여넣고 "붙여넣은 내용 적용"을 누릅니다. (붙여넣기용 엑셀 양식: `판매데이터_붙여넣기양식.xlsx` 참고)
6. 화면 맨 아래 "AI 리포트 프롬프트 생성"에서 보고 목적을 선택하고 "프롬프트 생성"을 누르면, 지금까지 입력한 집계 수치로 AI 요약용 프롬프트가 만들어집니다. 복사해서 ChatGPT 등에 붙여넣어 사용하세요. (이 화면은 AI를 직접 호출하지 않으며, API 키도 필요 없습니다.)

### 2) 수입 영업이익 계산 (`import-profit-calculator.html`)

1. 파일을 열고, 조회 년월을 선택합니다.
2. 제품별로 "이번 달 매출"을 입력합니다.
3. 입고 기록별로 수입일자·수입물량·수입원가·창고보관비·운송비를 입력하면, 비용 합계와 영업이익(매출−비용)이 자동 계산됩니다.

## 주의사항

- **이 화면에는 실제 고객명·연락처·계약조건 등 민감정보를 입력하지 마세요.** 테스트 단계이며 아직 보안 검토가 끝나지 않았습니다.
- **입력한 데이터는 저장되지 않습니다.** 새로고침하거나 창을 닫으면 모두 사라집니다. (향후 데이터베이스 연동 예정)
- **로그인 기능이 없습니다.** 파일을 열 수 있는 사람은 누구나 내용을 보고 수정할 수 있습니다. 외부에 공유하지 마세요.
- 계산 결과(매출, 재고, 영업이익)는 참고용입니다. 실제 정산 전 반드시 원본 수치와 대조해주세요.

"어때요?" 대신, 아래처럼 구체적으로 남겨주시면 반영이 빠릅니다.

- 어느 화면, 어느 칸에서 막혔는지 (예: "수입 제품 카드의 입고 기록 표에서 날짜 형식이 헷갈렸어요")

- 원하는 방향 (예: "표 대신 카드형으로 보였으면 좋겠어요")
- 지금 당장 고쳐야 할 문제인지, 나중에 하면 될 개선인지 구분
